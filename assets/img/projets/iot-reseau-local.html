RéalisationImplementation

1. Acquisition et communication1. Acquisition and communication

La carte STM32 se connecte en Wi-Fi et publie les mesures de ses capteurs sur un broker MQTT. Le compteur d'énergie PZEM est lu par un ESP32 en Modbus RTU ; l'ESP32 joue aussi le rôle de serveur Modbus TCP pour rendre ces mesures accessibles sur le réseau. Des scripts Python récupèrent les deux flux et les enregistrent dans MySQL.

The STM32 board connects over Wi-Fi and publishes its sensor readings to an MQTT broker. The PZEM energy meter is read by an ESP32 over Modbus RTU; the ESP32 also acts as a Modbus TCP server to make these measurements available on the network. Python scripts collect both streams and store them in MySQL.

2. Alertes par e-mail2. E-mail alerts

À chaque nouvelle mesure, la valeur est comparée à un seuil. En cas de dépassement (surtension, température élevée, mouvement brusque…), l'alerte est enregistrée en base et un e-mail récapitulatif est envoyé automatiquement.

Each new measurement is compared with a threshold. When it is exceeded (overvoltage, high temperature, sudden movement…), the alert is stored in the database and a summary e-mail is sent automatically.

3. Tableau de bord Power BI3. Power BI dashboard

Un tableau de bord Power BI connecté à MySQL présente les grandeurs électriques et environnementales, leur évolution dans le temps et la liste des alarmes, avec des filtres par période.

A Power BI dashboard connected to MySQL shows electrical and environmental values, their evolution over time and the list of alarms, with filters by period.

4. Chatbot connecté aux données4. Chatbot connected to the data

Une application web (backend Python avec API REST et WebSocket) relie un modèle de langage (LLM) à la base de données : l'utilisateur pose une question en langage naturel — nombre de mesures, température d'une journée… — et obtient une réponse, ou un rapport PDF.

A web application (Python backend with REST API and WebSocket) connects a large language model (LLM) to the database: the user asks a question in natural language — number of records, temperature on a given day… — and gets an answer or a PDF report.
